대조 방법: 미리보기 캔버스와 내려받은 파일이 같은 `render()` 함수와 같은 픽셀 크기(1080×1080 / 1080×1350 / 1080×1920)를 씁니다.
내려받은 파일을 다시 읽어 미리보기 캔버스와 픽셀 단위로 비교한 결과, PNG는 세 비율 모두 차이 0이었고 JPEG는 손실 압축 오차만 있었습니다(평균 1/255 미만).
"검사 문구 넣기" 버튼으로 가장자리와 자동 줄바꿈이 보이는 문구를 넣어 확인할 수 있습니다.

## 확인 방법 (4줄)

1. ① 위치: https://terran1234.github.io/meme-card-studio-03/ 를 새 시크릿 창에서 엽니다. 로그인은 없습니다.
2. ② 행동(3단계): ⓐ `samples/sample.png`를 화면의 이미지 영역에 끌어다 놓고 문구를 바꿉니다 → ⓑ 화면비 `9:16`을 고르고 `PNG 내려받기`를 누릅니다 → ⓒ 템플릿 이름을 적고 `새 템플릿으로 저장`을 누른 뒤 페이지를 새로고침합니다.
3. ③ 통과 모습: 미리보기와 똑같은 모양의 `card-9x16.png`가 내려받아지고, 새로고침 뒤에도 방금 만든 템플릿이 목록에 남아 있습니다.
4. ④ 안 될 때 모습: 초록 "✓" 메시지 대신 빨간 "!" 메시지가 나옵니다(예: `samples/not-an-image.txt`를 놓으면 "지원하지 않는 파일 형식입니다"). 이때도 하던 작업은 그대로 남습니다.

## AI와 나의 판단 (3줄)

> 초안입니다. 이 작업 대화에서 실제로 있었던 일만 적었으니, 본인 기억과 다르면 고쳐서 제출하세요.

1. AI에게 맡긴 일: 편집기 코드 작성(이미지 불러오기·검사, 화면비·내려받기, 템플릿 저장, JSON 내보내기·가져오기), 화면 디자인, 극단 입력 검사표와 결함 수정, 검사 페이지와 문서 작성, 개인정보·비밀값 검색.
2. 직접 판단한 일: 과제 요구사항 카드를 하나씩 넘겨 만들 순서를 정한 것, 처음 화면이 "너무 대충"이라고 판단해 세련되게 다시 만들도록 요청한 것, 내려받기가 없는 것을 직접 확인해 지적한 것, GitHub에 올리는 방법을 Edge 확장 연결로 하기로 정한 것, 완성 이미지의 제작 구분("본인 제작")을 최종 확인하는 일.
3. AI 제안을 따르지 않은 일: GitHub 연결이 안 될 때 AI가 Git 설치나 웹 업로드를 대안으로 제안했지만, 지난 과제에서 됐던 Edge 확장 연결 방식을 다시 시도하기로 하고 그대로 진행했습니다.
