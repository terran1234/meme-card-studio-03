# JSON 세 종류 결과 (카드 5: 옮겨 쓰기)

템플릿을 `meme-card-templates.json`으로 내보내고, 다시 가져와 복원합니다.
가져오기는 **파일 전체를 먼저 검사하고, 하나라도 문제가 있으면 아무것도 저장하지 않습니다.** 성공하면 화면에 "가져오기 전 N개 → 후 M개"를 보여 줍니다.

- 자동 검사 페이지: `tests/import.html` (편집기를 서버로 띄운 뒤 열면 15건을 실행. 실행 전 이 브라우저의 템플릿을 백업하고 끝나면 되돌림)
- 가져오기 규칙: 같은 `id`는 파일 내용으로 덮어쓰고, 새 `id`는 추가하며, 기존의 나머지 템플릿은 그대로 둡니다. 합쳐서 30개를 넘으면 거부합니다.
- 필수 항목: `id`, `name`, `text`, `x`, `y`, `size`, `color`, `ratio` (`createdAt`, `updatedAt`은 선택)

## 세 종류 결과 요약

| 종류 | 예 | 결과 | 기존 템플릿 |
|---|---|---|---|
| **정상 JSON** (T03-C22) | 새 2개 + 같은 id 1개 | 가져오기 성공, 3개 → 5개, 같은 id는 덮어쓰기 | 나머지 유지 |
| **문법이 손상된 JSON** (T03-C23) | 닫히지 않은 JSON, JSON이 아닌 글자 | 저장 전에 거부, "JSON 문법이 손상되었습니다" | 3개 → 3개, 저장 내용이 글자까지 동일 |
| **필수 항목이 빠진 JSON** (T03-C24) | 두 번째 템플릿에 `name` 없음 | 전체 거부("2번째 템플릿: 필수 항목이 빠졌습니다 (name)"), 정상인 첫 번째 템플릿도 저장하지 않음 | 3개 → 3개, 저장 내용이 글자까지 동일 |

## 막히는 지점 점검: 잘못된 JSON 뒤 기존 목록이 사라지는 문제

지킨 순서: **전체 검증 → 통과했을 때만 저장 → 오류면 아무것도 바꾸지 않음 → 가져오기 전후 건수 대조**

- 검증은 저장 전에 끝내고, 검증 중에는 기존 데이터를 건드리지 않습니다.
- 저장소에서 읽을 때의 "고쳐서 받아 주기"(`sanitizeTemplate`)를 가져오기에는 쓰지 않습니다. 가져오기는 잘못된 값을 몰래 고치지 않고 거부합니다.
- 화면에서 가져온 파일도 같은 `importText()`를 거칩니다(파일 선택 → 1MB 이하 확인 → 텍스트 읽기 → 위 검증).
