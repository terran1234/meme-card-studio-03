# 템플릿 CRUD와 재접속 결과 (카드 4)

## 템플릿 데이터 항목

| 항목 | 설명 |
|---|---|
| `id` | 고유 ID(`crypto.randomUUID()`). 수정·삭제·불러오기는 이 값으로만 대상을 찾음 |
| `name` | 이름, 최대 30자 |
| `text` | 문구, 최대 200자 |
| `x`, `y` | 문구 위치(%) |
| `size` | 글자 크기(px) |
| `color` | 글자 색(`#rrggbb`) |
| `ratio` | 화면비(`1:1` / `4:5` / `9:16`) |
| `createdAt`, `updatedAt` | 만든 시각, 고친 시각 |

이미지는 저장하지 않습니다. 용량이 커서 브라우저 저장소(약 5MB)를 금방 채우기 때문이에요. 템플릿을 불러오면 지금 올려 둔 이미지 위에 문구·위치·크기·색·화면비가 적용됩니다.

저장 위치: `localStorage`의 `studio.templates.v1` (`{ version: 1, items: [...] }`)

## 확인 절차와 결과 (실제 버튼을 눌러 진행)

| 번호 | 한 일 | 결과 |
|---|---|---|
| C17 | 서로 다른 설정으로 3개 저장: 월요병 밈(1:1, 90px, 노랑) / 카드 뉴스(4:5, 60px, 하늘) / 스토리 표지(9:16, 120px, 빨강) | 목록 3개, 저장소에도 3개 |
| C18 | '카드 뉴스' 불러오기 (그 전에 문구와 화면비를 다르게 바꿔 둠) | 문구·위치 20%·크기 60px·색 #38BDF8·화면비 4:5가 적용되고 캔버스가 1080×1350으로 바뀜 |
| C19 | '스토리 표지' 수정: 문구, 크기(120→70), 이름(→ 스토리 표지 v2) 변경 후 수정 저장 | 그 항목만 바뀌고 나머지 2개는 그대로. 저장소도 동일 |
| C20 | '월요병 밈' 삭제 (삭제 → "삭제할까요?" → 삭제 확인) | 그 항목만 사라지고 나머지 2개 유지. 저장소도 동일 |
| C21 | 페이지 새로고침 | 목록·수정 내용·삭제 결과가 그대로 유지되고, 새로고침 뒤에도 불러오기가 동작 |

## 막히는 지점 점검: 수정·삭제 대상이 바뀌는 문제

배열 위치를 쓰면 다른 탭이나 다른 동작으로 목록이 바뀔 때 엉뚱한 항목이 지워질 수 있습니다. 일부러 이 상황을 만들어 확인했습니다.

1. 목록 [카드 뉴스, 스토리 표지 v2, 삭제될 예비]에서 '삭제될 예비'를 눌러 삭제 확인 대기 상태로 둠(3번째 위치)
2. 다른 탭이 저장소 맨 앞에 '다른 탭에서 추가'를 끼워 넣음 → '삭제될 예비'가 4번째 위치로 밀림
3. '삭제 확인'을 누름

결과: **'삭제될 예비'만 삭제**되고 '다른 탭에서 추가'는 그대로 남았습니다(화면과 저장소 모두 [다른 탭에서 추가, 카드 뉴스, 스토리 표지 v2]).

지킨 원칙:
- 안정된 ID 사용, 화면 요소의 위치나 배열 번호로 대상을 정하지 않음
- 바꾸기 직전에 저장소를 다시 읽고, 그 위에서 ID로 찾아 바꾼 뒤 저장
- 저장한 뒤 그 저장된 데이터로 화면을 다시 그림
- 다른 탭에서 바뀌면(`storage` 이벤트) 이 탭도 저장된 내용으로 다시 그림

## 안전 점검

| 입력 | 결과 |
|---|---|
| 저장소 값이 깨진 JSON | 앱이 멈추지 않고 빈 목록으로 시작. 깨진 원본은 `studio.templates.v1.corrupt`에 따로 보관하고 안내 메시지 표시 |
| 이름이 `<img src=x onerror=alert(1)>` | 화면에 글자 그대로 표시되고 `<img>`가 만들어지지 않음(0개) |
| 범위 밖 값(x=999, y=-5, size='abc'), 잘못된 색·화면비 | 안전한 값으로 보정(x=100, y=0, size=96, color=#ffffff, ratio=1:1) |
| id가 없거나 형식이 나쁜 항목, 문자열·null, 중복 id | 걸러서 버림 |
| 저장 불가 브라우저(저장소 차단) | "새로고침하면 사라져요" 경고를 표시하고 메모리에서만 동작 |
| 30개 초과 저장 | 최대 30개 안내 메시지 |

## 한계

- 템플릿은 **이 브라우저 안**에만 저장됩니다(서버 없음). 다른 기기나 다른 브라우저와는 공유되지 않으며, 사이트 데이터를 지우면 함께 지워집니다. 카드 5의 JSON 내보내기·가져오기가 이 한계를 보완합니다.
- 실제로 확인한 환경은 Edge 한 곳입니다. 시크릿 창에서는 창을 닫으면 저장소가 비워지는 것이 브라우저의 정상 동작입니다.
