### 공개 화면과 배포 파일

- 화면에 나오는 것은 사용자가 직접 넣은 문구·이미지·템플릿뿐이며, 이름·이메일·연락처 같은 값을 받거나 보여 주지 않습니다.
- 앱 코드(`index.html`, `app.js`, `templates.js`, `style.css`)에는 **로컬 파일 외의 주소·네트워크 요청(`fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket`)·쿠키·`innerHTML`·`eval`이 없습니다.** 외부 폰트·CDN·분석 도구도 쓰지 않아서 사용자의 이미지와 문구는 브라우저 밖으로 나가지 않습니다.
- 템플릿은 사용자 브라우저의 `localStorage`에만 저장됩니다.
- 사용자가 입력한 문자열(템플릿 이름, 파일 이름)은 항상 `textContent`로 넣어 HTML로 해석되지 않습니다(`<img onerror>` 이름 검사 통과).
